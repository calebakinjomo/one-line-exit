The funniest single-line resignation letter I could write (109 characters, one line):

> I hereby resign: after two years of being told we are a family, I have decided to finally run away from home.

Two years of "we're a family here" — and the only honest exit is the one every kid dreams of: running away from home.

## Run it

```sh
python3 main.py
```

It prints the line and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), the file the make.fun program/v1 harness grades.
